## Why

当前游戏在玩家成为黑洞且物质达到 5000 时，会**瞬间**弹出「另一个宇宙」静态结局界面。这个收尾过于平直，缺少宇宙进化终点应有的仪式感。我们希望把结局改造成一段可播放的**宇宙创生动画**：在最终阶段，所有天体向玩家聚集、收缩成一颗发亮的小蓝点，随后爆炸扩散为一片星空——以此作为「另一个宇宙」的开场，强化「进化尽头即创世」的叙事闭环。

## What Changes

- **结局触发方式**：将「黑洞且物质 5000」从「立即弹出结局界面」改为「进入结局动画流程」（游戏循环暂停输入与战斗，进入 `cinematic` 状态播放动画）。
- **动画阶段（依次播放）**：
  1. **团聚**：屏幕内 / 所有在场天体（自由天体与环绕卫星）向玩家中心加速聚拢、缩小并被吸收吞噬，玩家体型随之膨胀。
  2. **蓝点**：聚拢完成后，玩家收缩为一点，变为**发亮的小蓝点**（高亮光晕、闪烁）。
  3. **爆炸**：小蓝点向外爆发成扩散的粒子 / 光波，铺满整个屏幕，形成一片新的星空。
  4. **结束**：爆炸动画结束后展示「另一个宇宙」结局界面与重玩入口（沿用现有 Overlay 风格）。
- **新增结局渲染能力**：以 fuickjs 现有原语（`Stack` / `Positioned` / `Container` / 渐隐渐显 / 光晕 `boxShadow`）实现上述分阶段动画，不改动框架层。
- **动画计时驱动**：结局动画复用固定步长循环推进阶段进度（阶段时长 / 插值），完成后置为 `win` 并展示结局界面。

## Capabilities

### New Capabilities
- `cosmic-evolution/cinematic-ending`：宇宙创生结局动画——团聚 → 蓝点 → 爆炸扩散 → 结束 四个阶段的时序、插值与渲染。

### Modified Capabilities
- `cosmic-evolution/evolution`：将「最终结局」由「立即展示结局界面」改为「进入结局动画流程，随后展示结局界面」。
- `cosmic-evolution/hud`：结局界面在创生动画播放完毕后展示；动画期间 HUD 隐藏或弱化。

## Impact

- **代码**：改动 `js/src/game/engine.ts`（结局状态机与动画推进）、`js/src/store/game.ts`（新增 `cinematic` 状态与动画进度字段）、`js/src/pages/game.tsx`（接入动画渲染层与输入屏蔽）、`js/src/components/GameField.tsx` 或新增 `components/CinematicEnd.tsx`（动画渲染）。
- **状态模型**：`GameStatus` 可能从 `playing | gameover | win` 扩展，或新增独立的动画子状态字段。
- **框架依赖**：仅使用 fuickjs 现有导出能力，**不修改框架层**；沿用固定步长循环驱动动画进度。
- **性能**：爆炸粒子数量需控制（如复用现有实体数量 / 有限粒子池），避免单帧 DSL 过大。
